# Лабораторная работа 2

Проект содержит решения трёх задач, реализованные на 12 языках программирования, включая ассемблер для третьей задачи.

## Структура проекта
.    
├── lab2_task1/ Решения задачи 1 (Шахматная доска)    
├── lab2_task2/ Решения задачи 2 (Валидация email)    
└── lab2_task3/ Решения задачи 3 (Неубывающие серии)    

## Задача 1: Шахматная доска с фигурой

**Условие**: дана доска N×M и строка команд (LRDU). Определить, можно ли выполнить все ходы, не выходя за границы доски, и найти начальную позицию.

## Задача 2: Валидация email-адресов

**Условие**: подсчитать количество уникальных email-адресов с учётом ограничений и лишних символов.

## Задача 3: Неубывающие серии

**Условие**: найти количество неубывающих подпоследовательностей в массиве.
